# 认识檐渡

檐渡（Yandu）让没有公网 IP 的本地设备为应用提供文件存储。原件保存在本机，业务服务器通过私有 TLS 隧道访问项目的目录、对象与版本；云端网关按需转发上传和下载，不同步整盘副本。

它可用于应用附件、照片、视频或其他项目文件。一台本地设备可以承载多个项目，各项目拥有自己的受管目录、配额和操作凭证。

## 两种项目模式

| 模式 | 适合的用途 | 访问方式 |
| --- | --- | --- |
| `application_storage` | 应用读写、续传、版本、回收站、按需媒体处理 | 业务服务调用 `/storage/v1/projects/{projectId}` |
| `readonly_mapping` | 将已有素材按资源前缀接到网站 | 原网站 URL → Nginx → 隧道 → 只读文件服务 |

新建通用存储项目时，只需项目 ID、空受管目录和配额，无需站点、业务域名或 Nginx。旧项目缺省保持只读映射，不会自动转换；原有文件通过[显式导入](/guide/business-integration#导入已有文件)进入存储项目。

## 文件在哪里

正式文件由独立 SFTPGo 进程操作。本地数据库保存名称、虚拟目录和版本记录，业务只处理 ID。目录改名和移动不要求业务知道物理路径。

上传先进入本机暂存，完成长度和内容校验、正式入库及数据库提交后才成为 `READY`。替换版本在新版本就绪前继续提供旧版本；软删除立即停止读取，后台执行可恢复移动。媒体预设缺省为空，选择后才生成缩略图、WebP、视频封面、MP4 或 HLS。

云端不提供备份或可离线读取的副本。本机断网、关机、休眠或卷不可用时，存储请求会失败，业务需要处理离线状态和重试。

## 本机管理与业务访问

| 入口 | 用途 | 默认地址 |
| --- | --- | --- |
| 本机管理页 | 项目、文件、回收站、凭证、容量和任务 | `http://127.0.0.1:18765/` |
| 本机存储 API | 开发时的业务接入、隧道源站 | `http://127.0.0.1:18770/` |
| SFTPGo 内部 API | Yandu 操作正式文件 | 回环 `18771`，不对业务开放 |
| 云端业务网关 | 业务服务器访问本地存储 | 默认回环 `19091` |
| 本文档网站 | 使用说明与参考资料 | 开发默认 `http://127.0.0.1:5174/` |

默认端口与可配置项见[端口与监听配置](./ports.md)。

浏览器通过业务自己的会话访问中转服务。项目密钥只放在业务服务器，不写入浏览器代码。管理页使用本机会话，需通过启动器或 `yandu ui` 打开。

## 平台与验证状态

目标基线为 macOS 14+ Apple Silicon、Windows 11 x64 和 Ubuntu 24.04 x64 云端。首版 macOS 覆盖 Apple Silicon。

当前是 **v0.2 开发与验证版**。各平台实测、服务身份和资源隔离状态统一见[验证记录](/reference/storage-verification)。

从[快速开始](/guide/getting-started)创建第一个项目；源码运行见[macOS 开发模式](/guide/development)或[Windows 开发模式](/guide/development-windows)。已有网站映射可继续使用[只读映射指南](/guide/readonly-getting-started)。
