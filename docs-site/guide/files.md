# 浏览目录与复制地址

“目录与文件”只浏览已建立项目的素材根目录，不提供整盘任意读取。

## 浏览目录

从项目列表点击项目名称，或进入“目录与文件”选择项目。点击子目录继续浏览，使用上方路径导航返回父级。

列表按页显示，每页最多 100 项，包含文件名、大小和修改日期。目录列表只在管理页内可见，访问者不能用资源 URL 浏览目录。

## 预览与复制地址

只有命中已登记资源范围的文件才显示资源地址：

```text
项目根目录  D:/oss/blog
资源前缀    /blog/xxx/
文件        xxx/photo.png
资源地址    https://example.com/blog/xxx/photo.png
```

点击“复制地址”，把 URL 用于你的文章或业务页面。未发布、未验证的项目，其地址只供配置预览；出现地址不代表已经能公网访问。

“未在资源范围内”表示该文件未被这个项目登记的前缀覆盖。修改素材出口或资源范围之前，先检查原有文章发布规则。

## 创建子目录

点击“创建子目录”，输入名称并确认。目录会在当前浏览位置创建。

服务账号需要实际写入权限；若素材目录仅授予读取权限，创建会返回权限错误。授权根目录不会隐式替你放宽 Windows ACL。

## 链接与文件类型

符号链接、junction 或 reparse point 会显示阻断或读取错误。不要通过链接把密钥、配置或其他目录混入发布范围。

当前发布策略只允许约定媒体类型。HTML、JavaScript、SVG 和未知扩展名不能作为业务素材直接发布。目录内出现文件不代表它一定符合 [访问策略](./access.md)。

## 文件的增删改

图片、音视频由你原来的工具或素材流程写入本地。普通文件更新不要求重启云端，但素材仍需符合当前缓存策略和发布规则。

本版管理页不提供上传、覆盖或删除素材文件的 API。删除项目映射也不会删除这些文件。
