# 文件、版本、回收站与凭证

本页操作针对 `application_storage` 项目。在 18765 管理页选择「通用应用存储」，用顶部选择器切换项目。旧网站素材的路径浏览见[只读映射文件指南](./files.md)。

## 项目与目录

首次创建见[快速开始](./getting-started.md)。项目显示 `active` 后才进行文件操作；初始化中的项目可稍后刷新状态。停用不会清空文件，会拒绝业务访问并使活动请求停止。

「文件」页显示当前目录的名称、大小和操作。点击目录进入，用「根目录」或目录层级返回。「加载下一页」读取后续条目。

点击「新建目录」，输入名称并保存。名称不能包含路径分隔符，不能是 `.` 或 `..`，不能有首尾空白。同目录同名返回冲突；中文和中间的空格可用。

「重命名 / 移动」打开页内对话框。修改名称，浏览目标目录并保存；对象 ID 保留。并发修改可能返回版本冲突，刷新后再核对。目录不能移动到自身或自己的子目录。

## 上传与续传

「上传文件」可选多个文件，管理页逐个传输。默认只保存原件；图片或视频的处理需求先在预设中勾选，再上传，详见[媒体处理](./media.md)。

进度有两个阶段：

1. Tus 分块传输到本机暂存，进度到 100%。
2. 校验长度与 SHA256、由 SFTPGo 入库、提交数据库，显示「上传完成」。

字节传完不等于对象就绪，业务查询到 `READY` 后才读取。网络短暂中断由 tus-js-client 重试；同一浏览器重新选择未完成的同一文件，管理页根据已保存的意图和续传记录尝试恢复。不要在续传中换文件内容、凭证或目标项目。

退出浏览器会中止当前页面的传输，未就绪对象不会成为可下载文件。失败后先查看错误及[排查指南](./troubleshooting.md)，不要修改暂存 `.info` 或绕过入库校验。

## 下载、替换与历史版本

点击「下载」读取当前原件。服务支持 HEAD、Range、ETag 和条件请求，可由业务实现断点读取。

「替换版本」选择新文件，仍使用同一对象。上传携带当前版本条件，新版本就绪前继续提供旧版本。两个请求同时替换时只有一个能提交，另一个报告冲突；刷新后确认当前版本再处理。

「版本」列出历史原件及 SHA256、大小、创建时间；用「下载此版本」读取指定版本。当前没有版本清理入口，历史版本也计入配额。

## 回收站与恢复

点击「删除」，在页内确认移入回收站。目录删除包括全部子项，确认框会说明范围。删除后原件及派生物立即不可读，正式移动由后台完成。

进入「回收站」点击「恢复」。若原父目录已删除、同位置已有同名条目或移动操作仍未完成，服务会拒绝恢复，先处理相应冲突。操作为后台恢复时可在「操作」页查看状态，再刷新文件列表。

**回收站不自动清空，删除不会立即释放配额。** 当前没有永久清空回收站的管理按钮或业务 API。恢复目录时不会把更早单独删除的其他文件一起恢复。

## 媒体产物与任务

上传时选择预设，或在已有文件行勾选预设后点击「处理所选预设」。在「媒体任务」查看 `queued`、`running`、`succeeded`、`failed` 或 `cancelled` 等状态。任务 ID、对象和版本帮助对应处理结果。

「派生文件」列出当前版本的 WebP、封面、MP4、HLS 和 `metadata.json`，可用受鉴权链接下载。替换或删除后，旧任务不能重新恢复文件；历史原件和当前派生物的可读范围不同。

## 容量与空间预留

页面展示已用、预留和项目配额。已用包括所有原件版本、回收站和媒体产物；预留包括正在上传、提交和媒体工作区需要的空间。

除了项目配额，还需底层卷/容器有足够空间。Windows 按固定 NTFS 卷协调，macOS 按共享 APFS 容器协调。即使原件能放下，也可能因暂存和工作区预算不足返回 507。

扩容、清理与迁移先按[维护流程](./storage-maintenance.md)核对，不直接删除正式对象或修改数据库。

## 项目凭证

「凭证」页创建操作凭证，原文只显示一次。保存到业务服务端的秘密配置，关闭显示后不能再次读取原文；遗失时新建并撤销旧凭证。

| 权限 | 用途 |
| --- | --- |
| 读取 `read` | 列表、原件、版本、派生物、容量、能力、任务与操作查询 |
| 上传 `upload` | 上传意图、Tus 创建及续传、上传状态查询 |
| 目录与名称 `metadata` | 新建目录、改名、移动 |
| 删除 `delete` | 文件或目录软删除 |
| 恢复 `restore` | 回收站列表及恢复 |
| 媒体处理 `process` | 上传时指定处理预设、随后提交媒体任务 |

凭证限定当前项目，不能访问其他项目。撤销后新请求拒绝访问，活动传输和任务提交也会停止；实现目标为五秒内停止，阻塞 PATCH 的实测见[验证记录](/reference/storage-verification)。

项目密钥不放进网页、移动客户端或下载 URL 查询参数；浏览器通过[业务会话中转](./business-integration.md)。本机管理会话和项目凭证是不同的认证入口。
