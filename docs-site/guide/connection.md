# 导入连接包

连接包由你自己的云端安装器生成。它把设备与已授权的网站绑定，使本机可以自动更新资源路径。

## 在管理页导入

1. 用桌面快捷方式或 `yandu ui` 打开管理页。
2. 进入“服务器连接”，选择 `.yandu-profile` 文件。
3. 输入单独交付的连接包口令。
4. 点击“导入并配对”。

页面会显示设备身份、SSH 主机指纹、授权域名和页面范围。连接包上限为 256 KB。

导入后项目保持停用，不能把已有资源自动全部公开。导入新材料会中断旧隧道并建立新配置，按项目重新确认应用。

## 测试配置通道

点击“测试配置通道”。通过表示 SSH 主机指纹和设备站点授权检查成功。

“连接材料已导入”只说明本地材料存在；“隧道客户端运行”只说明进程正在运行。单个项目是否真正生效，还需要隧道注册、入口同步和实际资源验证。

## 从命令行导入

```powershell
yandu connection import .\main.yandu-profile
```

口令由终端读取，不放在命令参数或日志中。

## 指纹改变时

若报告 `SSH_HOST_KEY_MISMATCH`，先由服务器管理员确认主机变化原因，再通过可信配对流程更新材料。工具不会自动信任改变后的服务器。

口令错误、文件损坏或连接材料无效会使导入失败。不要用示例域名或他人的连接包替代自己的授权站点。

配对材料的轮换流程见 [运维与凭据轮换](../reference/operations.md)。
