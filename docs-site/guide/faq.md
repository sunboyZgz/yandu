# 常见问题

## 文件会上传到云端吗？

默认不会。云端请求通过隧道回到本机，由本地文件服务读取并流式返回。它不提供云端备份或高可用副本。

## 本机关机后网站会怎样？

云端页面继续运行，本地资源失去源站。断网、休眠或磁盘不可读也会使资源不可用。

## 关闭浏览器会停止服务吗？

不会。管理页和后台服务分离；使用快捷方式或 `yandu ui` 可再次打开页面。

## 为什么直接打开管理地址会要求本机启动？

回环地址仍有本机会话保护。启动器会取得一次性票据并兑换会话；没有授权会话时，直接打开地址不会获得目录管理能力。

## 可以把整个 `/blog/` 指向本地吗？

本版不允许。登记比页面基础路径更深的资源前缀，例如 `/blog/xxx/`，以保留页面、业务 API 和前端构建资源。

## 为什么保存后图片仍无法访问？

保存创建草稿或待应用修改。需要点击“应用”，明确确认发布，再通过隧道、云端入口和实际资源核验。

## 可以在同一网站创建多个项目吗？

可以。项目和前缀不能重复或互相包含。已授权页面范围内新增前缀会自动更新 frpc 与 Nginx；新域名或新页面授权由管理员处理。

## 移动素材目录要改文章链接吗？

只修改根目录、保持页面基础路径和资源前缀不变时，URL 不变。保存并应用新目录；路由清单不变时不重载云端 Nginx。

## 删除映射为什么仍然返回 404？

这是保留旧资源范围的拒绝行为，避免掉回原网站的 SPA。只有独立“释放给网站”才交回这个路径。

## 密码保护会使用网站登录账号吗？

不会。它使用独立资源 Basic 凭据，不接网站 Cookie 或业务登录。业务身份、签名链接和上传授权尚未提供。

## 可以发布 HTML、JavaScript 或 SVG 吗？

默认不能。同域不同路径仍是同一浏览器源，本版媒体策略阻断这些主动内容。详见 [安全边界](../reference/security.md)。

## 可以用 UNC、网络盘或目录链接吗？

本版不承诺 UNC/映射盘可用，并阻断符号链接、junction 和 reparse point。使用独立、实际可读取的素材目录。

## Windows 用户需要安装开发环境吗？

完整客户端包已包含运行程序与组件，无需 Node.js、Go、Python 或 Docker Desktop。只有构建源码或文档站时需要相应开发工具。

## 是否已经通过真实公网与 Windows 验收？

当前是 v0.1.0 验证版。本机真实组件链路、安全测试与容量场景已验证；Windows 真机、Ubuntu 安装和真实公网尚需验收。完整证据见 [验证报告](../reference/verification.md)。
