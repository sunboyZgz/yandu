# 版本说明

## 2026-10-12：项目级 MP4 压缩上限

新增项目固定字节上限、上传时超限策略、规则快照、幂等媒体任务、单任务查询/取消及真实结果摘要。FFmpeg 完整压缩后按实测决定拒绝或授权保留开头，原件保持完整；管理页、OpenAPI、生成 SDK 与业务示例同步更新。macOS 原生及逐字节媒体验证见[MP4 验收记录](/reference/media-acceptance)；Windows 原生与服务生命周期仍待验收。

## 2026-10-12：端口配置与文档整理

新增各开发、安装和云端环节的默认监听地址、配置文件及固定端口限制。文档开发与静态预览统一支持 `DOCS_PORT`，默认回环 5174，冲突时停止；静态预览使用现有 Vite 服务器。删减首页宣传语和重复导航，架构页改为链接开发流程，重复的平台验收说明指向验证记录。

## 按需依赖与私有工具配置

2026-10-11

新增 `tools prepare/list/run`，先验证 PATH 和配置中的工具，再复用私有候选，仅补齐缺失项，记录绝对路径、来源、版本和 SHA256。检查原生架构及 FFmpeg 编码/封装能力，支持显式固定路径；启动与媒体进程使用已解析路径，保持系统 PATH 和用户工具。源码复用匹配锁文件的 npm 依赖；storage-only TLS 初始化改用 Go 标准库。Windows DACL 更新及两平台低权限生命周期仍需目标系统验收。

## 云端只读项目与磁盘清单

2026-10-11

增加云端 `yandu list`、`yandu disks` 和 JSON 输出，展示项目、配额、使用量、预留和去重后的受管 NTFS 卷/APFS 容器。新配对交付独立监控凭证；支持旧存储设备重新交付、明确标注离线快照和非零退出码。安装/升级创建云端命令别名，不扩大文件操作权限。Ubuntu 系统安装与 Windows 真机磁盘行为仍按平台验收门槛验证。

## 文档网站更新

2026-10-11

默认入门和开发流程改为 v0.2 通用存储，从本机项目开始，无需先准备域名或 Nginx。补齐文件与凭证、HEIC/视频任务、服务端 SDK、业务会话中转、OpenAPI 下载、连接和故障排查；保留独立只读映射指南与历史验证。此项是文档更新，不增加平台运行验收结果。

## v0.2 · 通用存储开发版

2026-10-10

新增通用应用存储项目、独立 SFTPGo、标准 Tus 续传、操作凭证、虚拟目录、条件版本替换、回收站、空间预留、持久媒体任务、HEIC 主图解码、SDK 和业务示例。增加 macOS launchd 与 Windows SCM 的完整原生组件包、安装入口，以及无需域名/Nginx 的 storage-only 网关。

macOS 已实测原生文件和媒体链路；Windows 真机及两平台服务身份/生命周期验收仍待执行。详细证据和复现命令见 [v0.2 验证记录](/reference/storage-verification)。

## v0.1.0 · 验证版本

2026-10-08

### 已实现

- 中文本机管理页：总览、项目、目录与文件、服务器连接和操作记录。
- 多项目、多前缀、草稿、明确发布确认、停用、删除与独立释放路径。
- SQLite 状态和 journal、版本检查、异步应用、重试与恢复流程。
- Caddy 文件服务、Go 请求检查、frp 资源隧道与受限 SSH 云端助手。
- Nginx 声明式配置、幂等回执、校验回退与资源探针。
- 加密连接包、SSH 指纹固定、TLS 身份验证、媒体白名单与独立密码保护。
- 两端程序、安装/升级/卸载脚本、组件版本锁、发布包和校验清单。
- VitePress 中文使用文档站，含本地全文搜索、用户指南和实际发布包下载。

### 已完成的验证

本机真实 Nginx → frp → Caddy 数据链路通过。验证覆盖三个项目自动登记、路径边界、中文与空格文件名、Range/HEAD/ETag、权限收紧、停用与通道失联。

容量场景实际注册 100 条路由、10 个项目，并核对并发小文件读取内容；这不是公网带宽或 Windows 视频性能承诺。

### 尚需目标环境验收

Windows SCM/ACL、真实 OpenSSH/sudo 限权、Ubuntu 干净安装、真实 DNS/HTTPS、公网与大文件视频场景仍需实测。详见 [完整验证报告](./reference/verification.md)。

## 当前不提供

生产业务账号系统、签名 URL、任意 TCP/UDP 代理、多设备租户管理、云端整盘副本和远程磁盘挂载。通用存储上传与媒体预设已实现，支持范围以对应验证记录为准。

功能扩展以实际需求和目标环境验收为准。
